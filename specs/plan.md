## Task CRUD 기능

### 목적
사용자가 할 일(Task)을 관리할 수 있도록 하여 생산성을 높인다.

### 범위
**포함:**
- Task 생성 (제목, 설명, 우선순위)
- Task 목록 조회 (필터링, 페이지네이션)
- Task 상태 변경 (todo → in_progress → done)
- Task 삭제

**제외:**
- 사용자 인증 (추후 구현)
- Task 카테고리/태그
- Task 공유/협업
- 알림 기능
